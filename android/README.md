# NekoDown Android

Versión móvil separada de NekoDown para Android 8 o superior.

## Compilar

1. Abrir esta carpeta con Android Studio.
2. Esperar la sincronización de Gradle.
3. Ejecutar `assembleDebug`.
4. El APK se genera en `app/build/outputs/apk/debug/app-debug.apk`.

La aplicación usa `youtubedl-android` y FFmpeg bajo GPL-3.0. Úsala sólo con contenido que tengas derecho a descargar.
